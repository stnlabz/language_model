CSS stands for Cascading Style Sheets.
CSS is a style sheet language used to control the presentation of documents.
CSS is commonly used to style HTML documents.
HTML primarily defines document structure and semantics.
CSS primarily defines presentation and layout.
CSS is not HTML.
CSS is not JavaScript.
CSS is not a server-side programming language.
CSS can control colors, typography, spacing, sizing, borders, backgrounds, and layout.
A CSS rule normally consists of a selector and a declaration block.
A selector identifies the elements to which a CSS rule applies.
A declaration block contains one or more CSS declarations.
A CSS declaration consists of a property and a value.
CSS declarations are normally separated by semicolons.
A property identifies the presentation characteristic being configured.
A value specifies the setting assigned to a CSS property.
The syntax selector { property: value; } represents a basic CSS rule.
CSS comments begin with /* and end with */.
CSS can be written inline using the style attribute.
CSS can be embedded in an HTML document using the style element.
CSS can be stored in an external stylesheet.
External stylesheets commonly use the .css filename extension.
An HTML document can load an external stylesheet using the link element.
External stylesheets allow multiple HTML documents to share presentation rules.
Separating CSS from HTML generally improves maintainability.
The cascade determines which CSS declarations apply when multiple declarations target the same element.
CSS means Cascading Style Sheets because applicable style rules participate in a cascade.
The cascade considers factors including origin, importance, specificity, and source order.
Specificity helps determine which competing selector takes precedence.
Source order can determine the winning declaration when otherwise competing declarations have equal precedence.
The !important annotation changes the priority of a CSS declaration within the cascade.
Using !important unnecessarily can make styles harder to maintain.
Inheritance allows some CSS property values to pass from an element to its descendants.
Not every CSS property is inherited.
Text-related properties are commonly inherited.
Layout-related properties are commonly not inherited.
A user agent stylesheet is a browser's built-in default stylesheet.
Browser defaults can cause elements to have presentation even when no author stylesheet is provided.
A type selector selects elements by HTML element name.
The selector p selects p elements.
A class selector selects elements according to their class attribute.
A class selector begins with a period.
The selector .notice selects elements having the notice class.
An ID selector selects an element according to its id attribute.
An ID selector begins with a hash character.
The selector #header selects the element whose id is header.
An attribute selector can select elements according to attributes or attribute values.
The universal selector * can select all elements within its applicable scope.
Selectors can be combined to express relationships between elements.
A descendant combinator selects elements nested within another matching element.
A child combinator selects direct children of another matching element.
The child combinator is represented by >.
The adjacent sibling combinator is represented by +.
The general sibling combinator is represented by ~.
A selector list allows the same declarations to apply to multiple selectors.
Selectors in a selector list are separated by commas.
A pseudo-class represents an element in a particular state or relationship.
Pseudo-classes begin with a colon.
:hover can select an element while a pointing device is positioned over it.
:focus can select an element that currently has focus.
:checked can select a checked form control.
:first-child can select an element that is the first child of its parent.
:nth-child() can select elements according to their position among siblings.
A pseudo-element represents a stylable part or generated portion of an element.
Pseudo-elements are commonly written using two colons.
::before can generate a pseudo-element before an element's content.
::after can generate a pseudo-element after an element's content.
Generated CSS content should not be relied upon as the sole source of essential document information.
CSS specificity is influenced by the components of a selector.
ID selectors have greater specificity than class selectors under ordinary specificity comparison.
Class selectors, attribute selectors, and pseudo-classes contribute to specificity.
Type selectors and pseudo-elements contribute to specificity.
A more specific selector can override a less specific selector when their declarations otherwise compete in the same cascade context.
CSS source order matters when competing declarations have equivalent cascade priority and specificity.
The box model describes how CSS represents the dimensions and spacing of an element.
The CSS box model consists of content, padding, border, and margin areas.
The content area contains an element's content.
Padding creates space between content and the border.
A border surrounds the padding and content areas.
Margin creates space outside the border.
The width property can specify the width of an element's box according to its box-sizing behavior.
The height property can specify the height of an element's box according to its box-sizing behavior.
The box-sizing property controls how specified dimensions are calculated.
With box-sizing: content-box, specified width and height apply to the content box.
With box-sizing: border-box, specified width and height include padding and border.
The margin property controls outer spacing.
The padding property controls inner spacing.
The border property can define an element's border.
Top, right, bottom, and left sides can be styled independently.
CSS shorthand properties can set multiple related values in one declaration.
The margin shorthand can specify margins for multiple sides.
The padding shorthand can specify padding for multiple sides.
The border shorthand can specify border width, style, and color.
The display property affects how an element participates in layout.
display: block creates a block-level formatting behavior.
display: inline creates inline formatting behavior.
display: inline-block combines characteristics of inline and block layout.
display: none removes an element from normal rendering.
An element using display: none does not occupy its normal layout space.
Hiding an element with CSS does not provide security.
Content hidden by CSS can still exist in the document and be inspected by the user.
CSS must not be used as an authorization mechanism.
CSS must not be used to protect sensitive information.
The visibility property controls whether an element is visibly rendered while generally retaining its layout space.
visibility: hidden hides an element while generally preserving its occupied layout space.
The position property controls an element's positioning scheme.
position: static is the normal default positioning scheme for most elements.
position: relative keeps an element in normal flow while allowing positional offsets and establishing positioning context for certain descendants.
position: absolute removes an element from normal flow and positions it relative to an applicable containing block.
position: fixed positions an element relative to the viewport or another applicable fixed-position containing block.
position: sticky can switch between relative-like and fixed-like behavior according to scrolling conditions.
The top, right, bottom, and left properties can offset positioned elements.
The z-index property can influence stacking order within applicable stacking contexts.
A larger z-index value does not universally place an element above every other element because stacking contexts affect comparison.
Normal document flow is the default system used to arrange many HTML elements.
CSS can modify how elements participate in normal document flow.
Floats allow content to flow around an element.
The float property was historically used for page layouts but is primarily intended for floated content.
Modern layouts commonly use Flexbox or Grid instead of float-based page layout.
Flexbox is a CSS layout model designed primarily for one-dimensional layout.
A flex container is created using display: flex or display: inline-flex.
Direct children of a flex container become flex items.
The flex-direction property controls the main axis direction.
The default flex-direction is row.
flex-direction: column arranges the main axis vertically.
justify-content controls distribution and alignment along the main axis.
align-items controls alignment of flex items along the cross axis.
align-content affects distribution of multiple flex lines when applicable.
The gap property can create spacing between flex or grid items.
flex-wrap controls whether flex items can wrap onto additional lines.
The flex property is a shorthand for flex-grow, flex-shrink, and flex-basis.
flex-grow controls how available positive free space can be distributed to a flex item.
flex-shrink controls how a flex item can shrink when space is insufficient.
flex-basis specifies an initial main-size basis for a flex item.

A grid container is created using display: grid or display: inline-grid.
Direct children of a grid container become grid items.
grid-template-columns defines the columns of an explicit grid.
grid-template-rows defines the rows of an explicit grid.
The fr unit represents a fraction of available space in a grid layout.
The repeat() function can define repeated grid tracks.
Grid items can span multiple rows or columns.
The gap property can define spacing between grid tracks.
Flexbox and Grid solve different layout problems and can be used together.
Flexbox is commonly useful for arranging content primarily along one dimension.
Grid is commonly useful for layouts involving both rows and columns.
